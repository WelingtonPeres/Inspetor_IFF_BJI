# Diretrizes de Identidade Institucional — IFFluminense

Regras obrigatórias para uso da marca, cores e tipografia do Instituto Federal Fluminense no jogo **Inspetor IFF-BJI**.

> Fontes oficiais:

## 1. Logo

- **Arquivo de referência:** `logo-iff-campus-bom-jesus-do-itabapoana.png`
- **Composição:** Símbolo quadriculado (verde + 1 quadrado vermelho no canto superior esquerdo) + texto "INSTITUTO FEDERAL" (bold) + "Fluminense / Campus / Bom Jesus do Itabapoana" (regular).
- **Não recolorir, não distorcer, não rotacionar, não aplicar efeitos** (sombra, glow, contorno) sobre o símbolo.
- Respeitar área de proteção: margem livre ao redor da marca igual à altura de um quadrado do símbolo.
- Versão clara (texto preto) sobre fundos claros; para fundos escuros, usar variação oficial em negativo.

## 2. Posicionamento

- **Telas principais** (Menu, Loading/Splash): marca **obrigatória**, fixa no **rodapé, alinhada à direita**.
- **Telas de turno/gameplay** (Relatório, Respostas, Diagnóstico): marca **opcional** — pode ser omitida para não competir com a interface.

## 4. Tipografia

- **Open Sans** (Bold para títulos/marca, Regular para texto corrido).
- Usar Open Sans em telas institucionais (splash, menu, créditos, sobre).
- UI de gameplay pode usar segunda fonte de apoio, desde que não conflite visualmente com a marca.

## 5. Usos Não Permitidos (lista oficial)

1. Não rotacionar a marca.
2. Não distorcer (esticar/comprimir).
3. Não alterar as cores do símbolo ou tipografia.
4. Não usar outline/contorno na marca.
5. Não aplicar como marca d'água (opacidade reduzida).
6. Não desalinhar os elementos entre si.
7. Não alterar a tipografia da marca.
8. Não aplicar moldura.
9. Não estilizar a marca (sombras, glow, texturas, gradientes).
10. Não criar novas aplicações/composições fora do padrão oficial.

> Fonte: Manual de Uso da Marca dos Institutos Federais, p. 17 ("Usos incorretos").

## 6. Checklist por Tela Nova

- [ ] Tela "principal" (marca obrigatória, rodapé direito) ou "turno" (marca opcional)?
- [ ] Marca em área de proteção, sem distorção/rotação/outline/moldura/marca d'água?
- [ ] Cores pertencem à paleta institucional ou complementar?
- [ ] Textos próximos à marca em Open Sans?
- [ ] Layout pensado para 16:9 desktop (1920x1080)?

## 7. Histórico de Decisões

- Posicionamento da marca: rodapé direito em telas principais; opcional em telas de turno.
- Conceito de loading com foto real descartado — usar elementos sólidos.
- Conectores Canva e Figma adicionados para suporte ao design visual.
